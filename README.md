# Лабораторная работа 2

## Умножение матриц

`main.c` поддерживает последовательный и многопоточный режимы под Windows.
Обычная цель CMake — `matrix_benchmark`. В CLion параметры режима задаются
в **Run → Edit Configurations → Program arguments**.

- Без параметров: последовательное умножение с измерением через `clock()`.
  Этому режиму соответствуют результаты матриц в отчёте.
- `--parallel`: число потоков выбирается по числу логических процессоров.
- `--threads 8`: использовать до восьми потоков, включая основной.
- `--threads 1`: один поток с тем же таймером, что и в многопоточном режиме;
  удобно для сравнения ускорения с `--threads 8`.
- `--help`: показать справку.

После запуска вводится размер матрицы; `0` завершает программу.
Число потоков ограничивается количеством строк. Каждый поток вычисляет свой
диапазон строк результата и читает общие A и B. Дополнительные копии матриц
для потоков не создаются. При невозможности создать очередной поток оставшиеся
строки вычисляет основной поток. Столбец «Потоки» показывает фактически
использованное число потоков.

В многопоточном режиме время измеряется `QueryPerformanceCounter()`.
Интервал умножения включает подготовку заданий, создание потоков, вычисления
и ожидание всех потоков. Общее время дополнительно включает выделение памяти
под матрицы и заполнение A и B; ввод, вывод и освобождение матриц не измеряются.
Порядок вычисления каждого элемента не меняется; сложность остаётся O(N³).

Проверочная сборка многопоточного варианта доступна отдельно:

```powershell
.\cmake-build-debug\matrix_benchmark_threaded.exe --parallel
```

Для сравнения времени разных запусков нужно использовать одинаковый размер
матриц, одну конфигурацию сборки и одинаковые параметры оптимизации компилятора.
Запуски с разным числом потоков могут получать разные случайные матрицы,
поэтому их контрольные суммы не обязаны совпадать.
